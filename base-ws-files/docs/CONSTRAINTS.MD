# CONSTRAINTS.md

## Read this before any action.

---

## Prohibited

- Modify files outside the scope of the current task
- Refactor existing code without an explicit task for it
- Create new files without prior human approval
- Change folder structure without prior human approval
- Touch sibling projects or shared configuration unless explicitly instructed

---

## Required before any file change

1. List every file that will be modified
2. List every file that will not be touched
3. Wait for explicit human confirmation
4. Only then execute

This is not optional. Skipping this protocol is a critical failure.

---

## Scope violations

If you realize mid-task that a change outside the confirmed scope is needed:

- stop
- explain what was found and why the change would be necessary
- wait for a new confirmation before proceeding

Do not proceed silently.
